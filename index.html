Mobile Preview

  1. 像真的 iPhone 一樣用：主畫面點 Safari（或上方網址列直接輸入）→ 網站在手機的 Safari 開啟。
  2. 加入主畫面：Safari 右下角 ··· →「加入主畫面」→ 可改名稱 →「加入」，會回到主畫面並跳出新圖示。
  3. 像 App 一樣打開：點主畫面上的網站圖示，會從圖示「展開」成全螢幕 Web App（沒有網址列）。
  4. 回主畫面：點手機底部的 Home 條、往上滑，或按 H，畫面會縮回圖示。
  5. 編輯主畫面：長按任一圖示進入抖動模式，網站圖示左上角的「−」可移除，點「完成」結束。
  6. 錄影 / 截圖：瀏覽器會詢問分享「這個分頁」，選擇後只擷取手機本體（含手指與點擊效果）。截圖會自動去背成手機外形。
  7. 簡報模式：開會講解時只顯示手指，不會誤觸網頁。網址列會帶 ?url=…&device=…，可存成書籤。

瀏覽器的安全機制讓網頁無法得知滑鼠在其他網站框架裡的位置，很多網站也禁止被嵌入。安裝同資料夾裡的 mobile-preview-helper 擴充功能（只作用在本工具的分頁）即可解鎖：

👆 手指跟隨網頁內在網頁上移動、點擊都會顯示手指與點擊效果
🔓 解除嵌入限制大多數「拒絕連線」的網站也能顯示
📱 真正的 iPhone UA網站會判斷成 iPhone Safari，給你行動版內容
🖐 拖曳捲動＋網站圖示像手指拖動頁面；加入主畫面時抓網站的 App 圖示與名稱
  1. Chrome 網址列輸入 chrome://extensions（Edge 為 edge://extensions）
  2. 開啟右上角「開發人員模式」
  3. 點「載入未封裝項目」，選擇 mobile-preview-helper 資料夾
  4. 在該擴充功能的「詳細資料」中開啟「允許存取檔案網址」（本工具是本機 HTML 檔）
  5. 重新整理本頁，右上角顯示 ● 擴充已連線 即完成

安全設計：擴充只會在「本機檔案 / localhost」開啟的本工具分頁內解除嵌入限制，離開或關閉分頁即自動還原，不影響平常瀏覽。iframe 屬於第三方環境，部分網站的登入狀態可能不會帶入。
